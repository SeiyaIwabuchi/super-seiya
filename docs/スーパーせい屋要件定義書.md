**ステータス：** ドラフト v1.1

---

## 1. プロジェクト概要

### 1.1 背景

岩手県一関市内で30年以上営業する地元密着型のスーパーマーケット。近隣に大型スーパーが開業したことにより客数が減少傾向にある。地元の常連客には知られているが、引越してきた住民や若い世代への認知度が低い。娘がInstagramでお惣菜の写真を投稿しており、SNS経由での新規来店も見られはじめている。

### 1.2 目的

- 新規顧客（引越してきた住民・若い世代）への認知拡大
- 「人のつながり・鮮度・地元感」という大型スーパーにない強みを伝える
- 来店動機となる「今日のおすすめ商品」情報の発信

### 1.3 対象ユーザー

| ユーザー層 | 特徴 |
|---|---|
| 地域の新規住民 | スマートフォンで近隣のスーパーを検索する |
| 若い世代 | InstagramなどSNS経由で情報を得る |
| 既存の常連客 | 特売情報・おすすめ商品を事前に確認したい |

---

## 2. スコープ

### 2.1 フェーズ1（初回納品）

基本4ページの静的サイト制作。CMS・動的機能は含まない。

### 2.2 フェーズ2（追加開発）

CMS導入による「今日のおすすめ商品」「ブログ」機能の追加。

### 2.3 対象外（フェーズ1・2共通）

- 物販・EC機能
- 採用ページ
- 会員登録・ログイン機能
- SNS機能（コメント・シェア等）

## 6. デザイン方針

### 6.1 基本トーン

「ごちゃごちゃしていない、見やすく温かみのあるデザイン」をコンセプトとする。大型スーパーのチラシのような派手な赤・黄色は使用しない。地元の野菜や食材を大切にしているお店の雰囲気に合わせ、自然素材・木のぬくもりを感じさせる落ち着いた雰囲気を基本とする。

### 6.2 カラーパレット

| 役割 | 方向性 | 補足 |
|---|---|---|
| 背景・ベース | 生成り・オフホワイト系 | 食材の色が映えるよう白すぎない温かみのある背景 |
| メインアクセント | 深みのある緑系 | 野菜・自然を連想させる色。CTAボタン等に使用 |
| サブアクセント | 木材・土色系のブラウン | 温かみの補強。見出し装飾等に使用 |
| テキスト | ダークブラウン〜チャコール | 純粋な黒より柔らかく、読みやすい |

> ※ 赤・黄・オレンジの多用は避ける。食材写真の色が自然に映えることを優先する。

### 6.3 タイポグラフィ方針

- 読みやすさを最優先とし、スマートフォンでも文字が判読しやすいフォントを選定する
- 本文サイズは16px以上を確保する
- 見出しには温かみのある明朝体またはセリフ系フォントを検討する
- 本文にはシンプルで読みやすいゴシック体・サンセリフ系フォントを使用する

### 6.4 画像・ビジュアル方針

- 食材・お惣菜の写真が主役となるレイアウトとする
- 背景はニュートラルに保ち、写真の色彩を引き立てる
- 店主・農家さんの「顔が見える」写真を積極的に活用する
- 生成AIによるイメージ画像（野菜コーナー・鮮魚コーナー・精肉コーナー・お惣菜コーナー・地元産コーナー）を素材として使用予定

## 7. システム構成

### 7.1 フェーズ1

```
Astro（静的サイト生成）
    ↓ ビルド
Amazon S3（静的ファイルホスティング）
    ↓ 配信
Amazon CloudFront（CDN・HTTPS）
    ↓
エンドユーザーのブラウザ
```

### 7.2 フェーズ2（追加コンポーネント）

```
娘さん・店主
    ↓ コンテンツ入力
microCMS（Headless CMS）
    ↓ Webhook
GitHub Actions（自動ビルド・デプロイ）
    ↓
Amazon S3 + CloudFront
```

### 7.3 使用技術

| 区分 | 技術・サービス |
|---|---|
| フロントエンド | Astro |
| CMS（フェーズ2） | microCMS（無料プラン） |
| ホスティング | Amazon S3 |
| CDN | Amazon CloudFront |
| CI/CD（フェーズ2） | GitHub Actions |
| ドメイン管理 | お名前.com 等 |
| バージョン管理 | GitHub |
